# zg-sunce-tiles

Detailed 3D buildings (ZG3D 2022 LoD 2.2, Grad Zagreb, Otvorena dozvola) for
[Sunčane terase](https://zkristo.github.io/zg-sunce/), one file per 600 m chunk, streamed by the app when zoomed in.

Generated by `tools/build_tiles.py` in [zkristo/zg-sunce](https://github.com/zkristo/zg-sunce); every rebuild replaces
this repository's single commit, so its history does not grow. Do not edit by hand.
